# Q1: Linux commands and system documentation
Run these commands in a Linux terminal and capture your **real** results.

| Command | Purpose |
|---|---|
| `pwd` | Show current directory |
| `whoami` | Show current user |
| `date` | Show date/time |
| `uname -a` | Show kernel/system information |
| `cat /etc/os-release` | Show OS details |
| `ls -la` | List files including hidden files |
| `mkdir -p demo` | Create a directory |
| `touch demo/sample.txt` | Create an empty file |
| `cp demo/sample.txt demo/copy.txt` | Copy a file |
| `mv demo/copy.txt demo/renamed.txt` | Rename a file |
| `cat demo/sample.txt` | Print file contents |
| `df -h` | Show disk usage |
| `free -h` | Show memory usage (if supported) |
| `chmod +x system_profile.sh` | Make script executable |

Execute `bash system_profile.sh | tee system_output.txt` from this folder.
**Do not upload a fake system output.** Add screenshots to `Screenshots/`.
